# Cloud VM Monitoring Project

This project is designed to monitor CPU, Memory, and Disk usage on a virtual machine.
It can be deployed on any cloud VM (AWS EC2, GCP Compute Engine, Azure VM).

## Features
- Real-time monitoring using Python and psutil
- CLI output for system metrics

## Usage
1. Clone the repository
2. Run `pip install -r requirements.txt`
3. Run `python main.py`
